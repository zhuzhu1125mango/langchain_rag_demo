# envs/ 环境副本目录

本目录用于放置**本地/敏感的环境变量副本**（如 `.env.dev`、`.env.prod` 的临时副本），
不入版本库（`.gitignore` 已忽略本目录）。

## 用途
- 便捷地在不同分支/版本间切换环境配置
- 备份导出环境文件，避免误改 `.env.*` 原文件

## 命名约定
- 副本建议带日期后缀：`envs/.env.dev-YYYYMMDD`
- 长期备份请放 `backups/`（已忽略），本目录保持轻量、短期。

> 提示：真正的配置模板是根目录 `.env.example`，应用启动读取根目录 `.env.{dev|prod}`。
